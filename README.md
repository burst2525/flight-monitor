# ✈️ 格安航空券 リアルタイム監視＆iPhone即時通知システム

大阪（関空 KIX / 伊丹 ITM）を拠点に、**国内・東アジア・東南アジア・物価の安いヨーロッパ諸国**の航空券価格を24時間監視し、**「通常相場から大幅に値下がりしたメガセール」**が出現した瞬間にあなたのiPhoneへ直接プッシュ通知するシステムです。

---

## 💡 このシステムの強み

### 1. APIキー登録・会員登録は一切不要！
**面倒なAPI登録やアカウント作成は不要**です。Googleフライトから直接最新の空席・運賃データを取得する仕組みを搭載しているため、環境構築後すぐに本物のフライト価格を監視できます。

### 2. 「通常相場からの大幅値下がり（メガセール）」を自動検知
「いくらになったら安いのか分からない…」という場合でも安心です。  
システムが各路線の**通常相場（中央値）を自動学習・把握**し、通常価格から**「25%〜50%以上安くなった時（例: エアアジアで大阪〜台湾 往復1万円台、Peachで沖縄1.5万円など）」**だけをピンポイントで検知して通知します。

- **届く通知の例**：
  ```
  🚨【メガセール!】 大阪(関空) ➔ 台北(桃園) 18,200円
  通常相場より約57% OFF（-23,800円安）
  💰 往復総額: 18,200円 (通常: 約42,000円)
  🛫 運航: エアアジアX
  📅 日程: 2026-12-23 〜 2026-12-26
  👉 タップしてGoogleフライトで予約画面を開く
  ```

### 3. Macがスリープ・電源オフでも24時間監視（電気代・バッテリー劣化0）
GitHub Actions（完全無料枠）を活用することで、**Macを閉じていても、外出先でも、クラウド側で定期的に自動巡回**します。Macのバッテリー消耗や電気代を一切気にせず、24時間365日の監視が可能です。

## 📱 【ステップ1】iPhoneの設定（所要時間：30秒・登録不要）

1. iPhoneの **App Store** で **「ntfy」**（無料アプリ）をインストール。
2. アプリを開いて右上の **「＋」** をタップ。
3. トピック名に `flight-alert-osaka-hiroki` と入力して **「購読」**。
4. これで準備完了！

---

## 🚀 【ステップ2】手動でリアルタイム検索を実行してみる

ターミナルで以下を実行するだけで、Googleフライトから本物の航空券価格をチェックし、相場より安い便が見つかればiPhoneに通知が飛びます：

```bash
cd 航空券通知
python3 main.py
```

---

## ☁️ 【ステップ3】Macスリープでも自動監視させる設定 (GitHub Actions)

Macの電源を切っていてもクラウド上で自動監視させる手順です：

1. GitHub（無料）で新しい **Privateリポジトリ**（非公開）を作成します（例: `flight-monitor`）。
2. この `航空券通知` フォルダの内容をプッシュします：
   ```bash
   cd 航空券通知
   git init
   git add .
   git commit -m "Setup flight monitor"
   git branch -M main
   git remote add origin https://github.com/あなたのユーザー名/flight-monitor.git
   git push -u origin main
   ```
3. GitHubリポジトリの **「Settings」➔「Secrets and variables」➔「Actions」➔「New repository secret」** に以下を登録します：
   - `NTFY_TOPIC`: あなたのntfyトピック名（例: `flight-alert-osaka-hiroki`）

これで設定完了です！  
GitHubが自動で **毎日 朝・昼・夕方・夜（7:00, 12:00, 18:00, 22:00）** に巡回し、格安チケットが出た瞬間にiPhoneへ通知が届きます。
